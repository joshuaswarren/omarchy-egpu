# Licenses

Our scripts and documentation use the [MIT license](LICENSE).

Kernel patches retain their original per-file licenses, normally GPL-2.0-only or GPL-2.0-or-later. Read each patch's SPDX identifier and original source notices. The MIT license does not replace them. Mesa patches retain their original MIT notices. A config fragment or recipe does not change the kernel's license.

GPU firmware remains under the vendor's terms. Install it through the official package linked in the card guide. This repository contains no GPU firmware, Apple firmware, or files extracted from an operating-system image.

Patch manifests state the base revision, license, and upstream status. An empty patch series means no driver source patch is carried for that route.
